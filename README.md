# Mavagu Tech LLC

A professional website for Mavagu Tech LLC, a technology company specializing in innovative software solutions, IT consulting, and digital transformation services.

## Project Structure

```
/
├── index.html          # Main HTML page
├── css/
│   └── styles.css      # Main stylesheet
├── js/
│   └── main.js         # JavaScript functionality
└── README.md           # This file
```

## Features

- Responsive design that works on desktop, tablet, and mobile devices
- Modern, professional styling with smooth animations
- Mobile-friendly navigation with hamburger menu
- Service showcase section
- Company information and values
- Contact form with client-side validation
- Smooth scrolling navigation

## Sections

1. **Hero** - Main landing section with company tagline and call-to-action
2. **Services** - Overview of services offered (Software Development, IT Consulting, Cloud Solutions, Cybersecurity, Digital Transformation, Managed Services)
3. **About** - Company information, statistics, and core values
4. **Contact** - Contact information and message form
5. **Footer** - Quick links and additional navigation

## Development

This is a static website that can be served directly. No build process required.

## Deployment

The site is configured for deployment on Netlify.
